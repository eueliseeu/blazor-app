# Projeto Blazor

Este é o meu primeiro projeto em Blazor, desenvolvido para aprender os conceitos básicos de criação de aplicações web com .NET e Razor Components realizado em sala de aula.

## Tecnologias

- .NET
- C#
- Blazor
- ASP.NET Core

## Estrutura do projeto

- `Components/` — páginas, layout e componentes da interface.
- `wwwroot/` — arquivos estáticos como CSS e bibliotecas.
- `Program.cs` — configuração da aplicação.
- `appsettings.json` — configurações da aplicação.

## Como executar

1. Abra o terminal na pasta do projeto.
2. Execute:

```bash
dotnet restore
```

3. Em seguida:

```bash
dotnet run
```

4. Acesse a URL indicada no terminal, normalmente:

```text
https://localhost:5001
```

ou

```text
http://localhost:5000
```

## Objetivo

Este projeto foi criado para praticar:

- criação de componentes Blazor;
- navegação entre páginas;
- uso de layouts e menus;
- desenvolvimento de interfaces com Razor.

## Observação

É um projeto inicial de aprendizado feito em sala de aula, então a estrutura pode ser simples e futuramente expandida com novos recursos.
